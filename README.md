# Arms

> A friendly note: Arms is part of Eurth's advent calendar, and its door opens on 10 December 2026. The code is public, the site isn't yet. Please don't spoil the surprise before the door opens.

Arms is a coat-of-arms maker that follows the rules of heraldry: it draws the shield, writes the blazon, and tells you when you've put colour on colour. It is one of the free worldbuilding tools by [Eurth](https://eurth.org), a worldbuilding and roleplay community since 2004, and will live at arms.eurth.org.

Nothing is built yet. The plan, and exactly where work stands, is in [roadmap.md](roadmap.md).
